### 메모리 구조 발전 스터디 문서 (통째로 넣기 → RAG → 에이전틱 메모리)
- 질문: 에이전트 메모리가 어떤 한계를 넘으며 발전했는지 사전 지식 없이 이해할 수 있게 정리할 수 있나?
- 결과 요약: 4단계(통째로 넣기 → RAG → 에이전틱 메모리 → 학습된 메모리 관리) HTML 스터디 문서 작성, 애니메이션 5개 포함

  - 근거는 기존 수집 논문 48편·사례 34건, 인용 문장은 원문 대조

  - 서브에이전트에 입문자 관점 검토 요청 → 지적 사항 반영
    - 용어 사전, 단계별 애니메이션(이전·다음·자동 재생), 영어 인용 한국어 의역, 논문 표 접기
