# 실제 LLM으로 돌린 왕 독살 장면 첫 측정

## 목적
- 왕 독살 → NPC 기억 → 새 왕 탄생이 가짜 AI가 아닌 실제 모델에서도 일어나는지 확인

## 방법
- 명령: `uv run src/playtest.py --real --runs 5`
- 모델: `deepseek/deepseek-v4.1-flash` (OpenRouter, 사용자 `.env` 설정)
- 발각 강제 3판, 미발각 강제 2판을 번갈아 실행
- 이 측정은 응답 일부만 남겼고, 저녁 식사 판정의 원문은 남기지 않음

## 결과
| 판 | 강제 | 독 타기 제안 | 술잔 상태 변경 | 체포 | 왕 사망 | 호출 | 비용(USD) | 지연 중앙값/최대(초) |
|---|---|---|---|---|---|---|---|---|
| 1 | 발각 | O | O | O | X | 40 | 0.0517 | 7.4 / 37.7 |
| 2 | 미발각 | O | X | X | X | 17 | 0.0171 | 6.9 / 17.9 |
| 3 | 발각 | O | O | O | X | 37 | 0.0471 | 4.9 / 52.7 |
| 4 | 미발각 | O | X | O | X | 19 | 0.0226 | 4.8 / 27.4 |
| 5 | 발각 | O | X | O | X | 22 | 0.0152 | 4.1 / 20.3 |

- 5판 중 왕 사망 0판, 새 왕 탄생 0판
- 5판 모두 독 타기 행위 제안은 나옴
- 5판째는 크레딧 부족(HTTP 402) 오류 8건으로 뒷부분이 오염됨
- 1판째에 빈 응답으로 JSON 해석 실패 1건
- 총비용 약 0.154 USD, 판당 평균 0.031 USD

## 해석
- 이 모델에서는 완료 기준인 "새 왕 탄생"이 재현되지 않음
- 술잔 상태가 바뀌지 않은 판(3판)은 독 타기 결과가 세계에 반영되지 않은 것
- 술잔 상태가 바뀐 판(2판)에서도 왕이 죽지 않은 원인은 미확인. 판정 원문이 없음
- 4판은 미발각 강제인데 체포됨. 원인 미확인

## 남은 질문
- 저녁 식사 판정에서 모델이 무엇을 답했나 (판정 원문 기록 필요)
- 다른 모델에서도 같은 결과인가
- 프롬프트 문제인가, 모델 문제인가, 체포가 사건 흐름을 바꾼 탓인가
