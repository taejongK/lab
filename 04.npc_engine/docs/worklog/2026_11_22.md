### 방을 따로 만들고 연결도로 잇는 공간 구조
- 질문: 게임 만들기에서 방이 하나밖에 안 만들어지는 이유는? 방을 추가하고 서로 연결하게 할 수 있나?
- 결과 요약: 새 게임 틀의 첫 방이 지도 전체를 차지해 다른 방이 모두 겹침으로 막혔음. 지도 한 장 구조를 버리고, 방마다 자기 지도를 갖고 연결도에서 문으로 잇는 구조로 바꿈
- 방법:
  - 위치를 (방, x, y)로 바꿈. 연결은 양쪽 방에 짝 문을 하나씩 두는 방식
  - 문에 들어서면 건너편 방 문 위에 섬. 문 위에서 바깥으로 누르면 되돌아감
  - 길찾기는 문을 지나 다른 방까지 탐색. NPC 일과와 AI 이동 모두 적용
  - 플레이 화면은 지금 방만 그림. 작은 방은 가운데 배치
  - 에디터 공간 탭: 방 연결도(끌어 배치, 눌러 선택, 두 방 눌러 연결) + 고른 방의 지도 편집. 문은 마주 보는 벽에 자동 생성
  - 성 시나리오를 새 형식으로 변환. 창살 너머 대화를 위해 "감옥 앞"과 "감옥"을 창살 있는 방 하나로 합침
  - 가짜 AI 자동 검사 통과 (독 타기 → 체포 → 계승 흐름 유지). 방 사이 길찾기, 문 짝 불일치, 끊긴 연결 검사 추가
  - 브라우저 확인: 방 추가 → 연결 → 저장 → 플레이 → 문 통과 → 되돌아오기, 콘솔 오류 0건
- 남은 문제:
  - 연결도는 마우스 전용. 키보드 조작 미지원
  - 문 위치를 직접 옮기는 기능 없음. 끊고 다시 이어야 함
  - 예전 한 장 지도 형식 시나리오는 열리지 않음. 저장된 게임이 castle뿐이라 영향 없음
  - 감옥 합병으로 갇힌 플레이어와 감옥에 온 NPC가 서로 목격 가능해짐
  - 동작 원리 문서(2026_11_05_game-mechanics.html)는 예전 지도 구조 기준. 미갱신
  - 실제 LLM으로는 미확인

### 홈에서 기존 게임 수정 진입
- 질문: 이미 만든 게임을 다시 열어 구조를 보고 고칠 수 있나?
- 결과 요약: 플레이 가능한 게임 카드에 "플레이"와 "수정하기"를 나란히 둠. 수정하기는 게임 만들기 화면에서 그 게임을 엶
- 방법:
  - 기존에는 완성된 카드 전체가 플레이 버튼이라 수정 진입로가 에디터의 불러오기 목록뿐이었음
  - 브라우저에서 수정하기 → castle 6개 방이 에디터에 열리는 것 확인
- 남은 문제: 수정 화면에서 저장하면 castle.json을 바로 덮어씀. 자동 검사가 castle의 방 이름·좌표에 의존

### 사람과 물건 위로 지나가지 못하게
- 질문: 캐릭터가 다른 캐릭터나 물건이 있는 칸을 그냥 통과하지 않게 할 수 있나?
- 결과 요약: 사람(쓰러진 사람 포함)과 바닥의 물건이 있는 칸은 막힘. 플레이어는 멈추고, NPC는 돌아가거나 길이 없으면 기다림
- 방법:
  - 서버가 이동마다 막힌 칸을 판정. 화면도 같은 판정으로 미리 막아 튀는 움직임 방지
  - NPC는 다음 칸이 막히면 막힌 칸을 피해 경로를 다시 찾음. 없으면 그 틱은 대기
  - 자동 검사 추가: 플레이어가 술잔·경비 쪽으로 이동 불가, 복도에서 막힌 경비가 아래 줄로 우회, 구석에 갇힌 경비가 겹치지 않고 대기
- 남은 문제:
  - 폭 1칸 통로에서 두 NPC가 마주치면 서로 비키지 않고 계속 대기할 수 있음
  - 문 칸 위에 누가 서 있으면 건너편에서 그 문으로 못 들어옴
  - 브라우저에서 직접 부딪혀 보지는 않음
